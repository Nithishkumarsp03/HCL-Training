# HCL Daily Tasks – Java Basics

This repository contains the Java tasks I completed as part of my HCL training.

The tasks mainly focus on understanding Java basics, JVM execution, arrays, type casting, operators, and memory-related concepts.

---

## Task 1 – Platform Information

### What I did

Created a simple Java program called `PlatformInfo.java` to check some information provided by the Java runtime and the operating system.

The program prints:

* Java version
* Operating system
* Number of available processors
* Maximum heap memory
* Free heap memory

I also compiled and ran the program directly from the terminal using `javac` and `java`, without using an IDE.

### Commands used

```bash
javac PlatformInfo.java
java PlatformInfo
```

I also checked the generated bytecode using:

```bash
javap -c PlatformInfo
```

And checked the classes loaded by the JVM using:

```bash
java -verbose:class PlatformInfo
```

### Output

The exact values can vary depending on the machine and JDK being used.

```text
Java Version: 21.0.x
OS: Windows 11
Processors: 12
Max Heap: 4096 MB
Free Heap: 300 MB
```

When using `javap -c`, the compiled bytecode of the `main()` method was displayed.

With `-verbose:class`, the JVM displayed the classes being loaded while the program was running.

## Task 2 – Monthly Usage Analyser

### What I did

Created `MonthlyUsageAnalyser.java` to analyse usage data for 12 months.

The program covers:

* Total usage
* Average usage
* Maximum usage
* Minimum usage
* Usage grading using the ternary operator
* Integer overflow
* Fixing overflow using `long`
* A 2-D array containing usage for 3 houses across 12 months

I also used constants for the usage limits instead of directly putting the values inside the logic.

### Output

```text
===== Monthly Usage Analysis =====
Total Usage   : 1975
Average Usage : 164.58333333333334
Maximum Usage : 250
Minimum Usage : 90
Usage Grade   : B

===== Integer Overflow =====
Maximum int value : 2147483647
After adding 1   : -2147483648

===== Using long =====
Maximum int value : 2147483647
After adding 1   : 2147483648

===== 3 Houses Usage =====
House 1: 120 180 95 210 150 175 220 130 90 160 195 250
House 2: 100 140 110 190 130 160 200 120 80 150 170 220
House 3: 200 220 180 250 210 230 270 190 160 210 240 280
```

### Concepts covered

The main things I understood from this task were how arrays are processed using loops, how type casting affects calculations, and how integer overflow happens when a value goes beyond the range of an `int`.

The 2-D array also helped me understand how data can be organised row-wise, in this case with each row representing a house and each column representing a month.
